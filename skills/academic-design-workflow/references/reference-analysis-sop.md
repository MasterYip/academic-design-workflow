# Reference Analysis SOP

Use references to discover principles and tokens, not to trace or clone. Record
source, license when known, purpose, and which observations are inferred.

Analyze hierarchy and reading order; layout and spacing; shape vocabulary,
corners, borders, connectors, and icons; surfaces, semantic colors, transparency,
and contrast; typography; then chart or motion conventions.

Write a structured analysis separating observations from proposed adaptations.
Map approved findings to semantic theme tokens, generate a small component module,
and render an original comparison proof. Promote components only after review.

Do not promise perfect font identification, hidden geometry recovery, or automatic
raster-to-vector reconstruction. Ask for correction when an inference materially
changes the design system.
