# Project Website SOP

Start from the paper's communication goal, not a generic landing-page template.
Define one primary action and an evidence sequence: contribution, visual result,
explanation, comparisons, resources, citation, and authors.

Compile the approved theme to CSS. Components may transform units for the medium,
but retain semantic roles, type relationships, shape grammar, and motion principles.
Reuse canonical figure exports rather than drawing approximate web-only versions.

Include only supported sections: hero, abstract, teaser, method, results,
comparison, video, code/data, BibTeX, acknowledgements, and team. Avoid repeated
card grids when a narrative sequence communicates more clearly.

- Preserve reading order when columns collapse.
- Set media dimensions to prevent layout shift.
- Make figures zoomable or link full-resolution versions.
- Provide keyboard focus, meaningful alt text, contrast, and reduced motion.
- Test narrow mobile, tablet, laptop, and wide desktop views.
