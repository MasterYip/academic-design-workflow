# Paper Figure SOP

Write the one-sentence reader takeaway. For a schematic, list entities,
relationships, direction, hierarchy, repeated structures, and exact visible text.
For a plot, record source data, transformations, comparison question, uncertainty,
and required scales.

For important overviews, create two or three different information structures in
monochrome: pipeline, layered system, temporal sequence, or data-flow graph.
Select based on reading order and explanatory value before visual polish.

- Use theme-bound Matplotlib primitives and semantic roles.
- Keep coordinates in layout functions and visual constants in the theme.
- Use alignment, whitespace, enclosure, and panel labels to express hierarchy.
- Pair color with shape, marker, line style, or label for critical distinctions.
- Keep visible prose short and qualification in the caption.
- Test in grayscale and at final column width.
- Export editable SVG/PDF plus a PNG preview.

Deliver data or provenance, rendering code, theme/version, dimensions, exports,
and a caption draft. Do not deliver only a bitmap.
